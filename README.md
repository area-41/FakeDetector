# FakeDetector
Python CV2 code to check if the image was generated by AI or not.

## AI Image Detector: Luminance-Gradient PCA Analysis

Este estudo simples implementa uma técnica de perícia digital baseada na análise estatística de gradientes de luminância para identificar artefatos de síntese em imagens geradas por Inteligência Artificial (GANs, Diffusion Models, etc.).

A técnica foca na microestrutura da imagem, revelando padrões de ruído e "checkerboard artifacts" que são invisíveis ao olho humano, mas estatisticamente distintos em imagens sintéticas.

## Como funciona?

O pipeline de detecção segue quatro etapas matemáticas fundamentais:

1.  **Conversão para Luminância ($L$):** Utilizamos a norma **ITU-R BT.709** ($L = 0.2126R + 0.7152G + 0.0722B$) para isolar a intensidade luminosa, onde a maioria dos artefatos de geração reside.
2.  **Cálculo de Gradientes Espaciais ($G_x, G_y$):** Através do operador de Sobel, extraímos as derivadas parciais da imagem. Isso captura como a luz muda em cada pixel.
3.  **Matriz de Covariância ($C$):** Os gradientes são achatados em uma matriz $M \in \mathbb{R}^{N \times 2}$ para calcular a covariância das variações espaciais.
4.  **Projeção PCA:** Aplicamos a Análise de Componentes Principais. Ao projetar a imagem no primeiro componente principal ($PC_1$), isolamos a direção de maior variância, tornando visíveis os padrões de reconstrução da IA.


## Diferença entre Real vs IA

* **Imagens Reais:** Apresentam gradientes orgânicos e ruído fotônico (shot noise) distribuído de forma estocástica e natural.
* **Imagens de IA:** Frequentemente revelam padrões repetitivos ou "manchas" de variância artificial, fruto das camadas de convolução transposta e algoritmos de upsampling.

## omo Usar

### Instalação

    git clone [https://github.com/seu-usuario/ai-pca-detector.git](https://github.com/seu-usuario/ai-pca-detector.git)
    cd ai-pca-detector
    pip install -r requirements.txt

### Analisar uma única imagem

    python main.py --image caminho/da/imagem.jpg

### Processamento em lote e log estatístico

    python batch_process.py


## Análise de Autovalores (Eigenvalues)

O arquivo eigenvalues_log.csv gerado permite comparar a "assinatura de energia" das imagens. IAs tendem a apresentar distribuições de variância (Eigenvalue 1 vs Eigenvalue 2) que fogem da curva de sensores ópticos CMOS convencionais.
